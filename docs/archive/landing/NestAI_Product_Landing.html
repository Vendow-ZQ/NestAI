统一模板无法满足需求，需要根据用户个性与生活方式进行精确的室内改动输出。 Uniform templates fail; need precise output based on lifestyle.

assets/images/painpoints/pain3-static.png

需要结合空间限制、经济预算以及真实生活习惯，普通用户缺乏专业设计知识。 Combining constraints, budget, and habits requires expertise.

Prompt 工程Prompt Engineering

融合多学科知识的 Prompt 设计 Multi-Domain Knowledge Fusion in Prompts

4 个精心设计的 Prompt，融合空间设计、空间心理学、行为经济学、文化研究。不是简单的 AI 调用，而是领域知识的系统化编码。 4 carefully crafted prompts fusing spatial design, environmental psychology, behavioral economics, and cultural studies.

P001 空间分析Space Analysis

Vision LLM 理解空间结构、物件布局、氛围特征。输出生活方式线索假设，供后续问卷验证。Vision LLM analyzes spatial structure and atmosphere.

空间类型学Spatial Typology 人体尺度Human Scale 身体感受Body Feeling 安全约束Safety
P002 干预规划Intervention Plan

基于生活方式对话生成三档干预方案。"三层一体故事"确保各档共享核心意图。Generates three-tier intervention plans based on lifestyle chat.

动线设计Circulation 习惯形成Habit Formation 摩擦成本Friction Cost 风格方向Style Direction
P003 反思信件Reflection Letter

生成温柔的一封信总结变化，给出下一个 Next。不设 KPI，不制造焦虑。Generates a gentle letter summarizing changes and suggesting next steps.

非评判语言Non-judgmental 叙事设计Narrative Design 隐私保护Privacy

UI 设计UI Design

从极简界面到严谨的设计规范 From Minimal UI to Rigorous Design Guidelines

"极简"不是简陋，而是克制。每一处留白、每一个圆角、每一种字重，都有其存在的理由。 "Minimal" isn't simple—it's restrained. Every whitespace, every radius, every weight has its reason.

色彩系统Color System

设计原则Design Principles

  • 使用 Noto Sans SC，中英统一字体Noto Sans SC for both languages
  • 4px 基础间距系统（4/8/12/16/24/32）4px base spacing system
  • 卡片圆角 8px，按钮胶囊形8px card radius, pill buttons
  • 页面边距 20px，一行最多 60 字20px padding, max 60 chars/line

禁止使用Prohibited

  • "高级感""质感"等样板间语言"Premium" "texture" showroom language
  • Blur shadow / 内阴影 / 新拟态Blur shadow / Inner shadow / Neumorphism
  • 旋转、弹性弹跳、视差动画Rotation, bounce, parallax animations
  • MBTI / OCEAN 等人格标签MBTI / OCEAN personality labels
  • 焦虑营销 / KPI / 截止日期Anxiety marketing / KPIs / Deadlines

AI 生图约束Image Gen Constraints

  • 不改变墙面颜色 / 地板材质No wall color / floor changes
  • 不改变窗户位置 / 光线方向No window / light direction changes
  • 不脱离原环境做氛围渲染No unrealistic atmosphere rendering
  • 只展示干预动作（添加/调整/优化）Show only interventions (add/adjust/optimize)
